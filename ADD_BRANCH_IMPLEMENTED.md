## 🚀 **How It Works**

### **User Flow:**
1. Click "Add Branch" button
2. Dialog opens with form
3. Fill in all required fields
4. Click "Create Branch"
5. Loading indicator shows
6. Branch saved to Firestore
7. Success message appears
8. Dialog closes
9. Branch list updates automatically (real-time)

### **Data Flow:**
```
User fills form
  ↓
Validation runs
  ↓
BranchModel created
  ↓
Repository.createBranch()
  ↓ (validates admin permission)
DataSource.createBranch()
  ↓
Firestore.collection('branches').add()
  ↓
Real-time stream updates UI
  ↓
New branch appears in list
```

## 🔒 **Security**

### **Permission Check:**
```dart
// In BranchRepository
void _validateAdminPermission(UserRole userRole) {
  if (userRole != UserRole.admin && userRole != UserRole.superAdmin) {
    throw const AppException.authorization(
      message: 'Only admins can manage branches',
    );
  }
}
```

### **Firestore Rules:**
```javascript
match /branches/{branchId} {
  allow create: if request.auth != null;
}
```

**Note:** Admin validation happens in the app layer for better UX.
